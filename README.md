# 📚 Design Patterns

Repositório de estudos sobre **Design Patterns (Padrões de Projeto)**, com exemplos práticos para entender como aplicar cada padrão no desenvolvimento de software.

## 🚀 Objetivo

Aprender e praticar padrões de projeto para escrever código mais organizado, reutilizável e fácil de manter.

## 🧠 Conteúdo

- **Creational**: padrões de criação de objetos
- **Structural**: organização e composição de classes
- **Behavioral**: comunicação entre objetos

## 💻 Tecnologias

Os exemplos podem variar entre linguagens como C++ ou JavaScript.

_Design Patterns: Elements of Reusable Object-Oriented Software_
